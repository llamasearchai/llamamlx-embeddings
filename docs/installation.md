# Installation

## Using pip

The recommended way to install LlamaMlx Embeddings is via pip:

```bash
pip install llamamlx_embeddings
```

## From Source

You can also install LlamaMlx Embeddings from source:

```bash
git clone https://github.com/llamasearchai/llamamlx-embeddings.git
cd llamamlx-embeddings
pip install -e .
```

## Dependencies

LlamaMlx Embeddings requires:

- Python 3.8+
- Other dependencies are automatically installed by pip
